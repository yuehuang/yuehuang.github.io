# 数据来源与版式标准

## 一、四个能力，各自从哪来

| 能力 | 来源 | 授权 | 实测 |
|---|---|---|---|
| **拼音** | [pinyin-data](https://github.com/mozillazg/pinyin-data) `pinyin.txt`（取第一个读音） | MIT | 20,892 个常用字 → JSON 267 KB |
| **笔顺（先写哪一笔）** | [hanzi-writer-data](https://github.com/chanind/hanzi-writer-data) 每个字 JSON 的 `strokes` **数组顺序** | Arphic PL | 9000+ 字，全量 29 MB |
| **字形（怎么画出来）** | 同上 `strokes`（SVG path） | Arphic PL | 矢量，可任意放大 / 改色 / 做描红，不需要装字体 |
| **占格位置** | 同上 `medians`（每条笔画的中心线坐标） | Arphic PL | 取首尾点 → 映射田字格九宫格 → **自动**生成「从左上起笔，到下方收笔」 |
| **顿挫（起笔顿 / 行笔 / 出锋）** | ❌ **无开源数据** | — | 公开数据只有轮廓和中心线，没有力度与节奏 |
| 朗读 | 浏览器 `speechSynthesis` / macOS `say -v Tingting` | — | 零成本，但引入屏幕时间，优先级低 |
| 互动描红打分 | [hanzi-writer](https://github.com/chanind/hanzi-writer) 的 quiz 模式 | MIT | 库自带，v2 用 |

**结论**：拼音、笔顺、字形、占格位置全都有现成开源数据；**只有"顿挫"要自己写**——但可以按**笔画类型**套模板（横/竖/撇/捺/点/钩/折 各一套，覆盖约 80%），剩下按字微调。一节课 16 字 ≈ 60 条，人工 2~3 小时。

## 二、版式标准（本项目的核心要求）

```
┌──────────────────────────────────────────────────┐
│ 范字 │ 空 │ 空 │ 空 │ 空 │ 空 │ 空 │   ← 第一行：范字打头，后面全是空格临写
│ 空   │ 空 │ 空 │ 空 │ 空 │ 空 │ 空 │   ← 第二行起：独立写
└──────────────────────────────────────────────────┘
  笔顺：竖 → 横 → 横        占格：竖压竖中线，短横在横中线上方，长横托底
```

1. **范字只占第一格**，其余全是空网格——**孩子直接在田字格里写，不必描红**。
   （已实现为默认模板「范字 + 空格」；另有「描红练习 / 笔顺分解 / 默写听写」三个模板）
2. **笔顺、占格说明是"附注"**，不能占掉练习区。
3. 描红可选（0~3 格）：不开 = 更省墨、更接近课堂生字本。描红只是入门脚手架，一两周后撤掉。

## 三、同类工具（只留做得成的三个）

| 站点 | 优点 | 与我们的差异 |
|---|---|---|
| [HanZiFun](https://rickytan.cn/HanZiFun/) | 功能最全：田字格/米字格、A3/A4/A5/Letter、横竖、导出 PDF、PWA 离线 | **没有"范字 + 空格"的混合版式**：笔顺模板整页是笔顺图，空白格模板又是纯空白，页面利用率低 |
| [喵字帖](https://miaozitie.80wdb.com/) | 工具箱定位：练字 + 听写 + 古诗 + 朗读 | 无占格讲解 |
| [ibeilly 汉字笔顺](https://ibeilly.github.io/hanzi-practice/) | 唯一挂在 github.io 且可用；笔顺动画 + 朗读 + 规范字表选字 | 无打印排版 |
