## 三、他们"更易用"在哪（可直接借鉴）

1. **模板优先，而不是一堆开关**（HanZiFun 最典型）：`描红练习 / 笔顺分解 / 空白格纸 / 文章临摹` 四个模板按钮，点一下换整页样式。我们现在是 8 个开关——家长要的是"我要描红页"，不是"我要把 trace 设成 3"。
2. **纸型 + 方向**：A5 / A4 / A3 / Letter × 纵向 / 横向。
3. **按钮就叫「导出 PDF」**（底层同样是浏览器打印，但家长看得懂）。HanZiFun 前端里 `PDF` 出现 137 次。
4. **格型切换**：田字格 / 米字格。
5. **PWA「安装」按钮 + 离线承诺**。
6. **整篇模式**：贴一段古诗/课文，自动拆字排页。
7. 喵字帖的标题已经叫「小学生练字与**学习工具箱**」——**和你"看板 + 多模块"的思路撞了**，说明方向对，但也说明纯做通用字帖没有优势。

## 四、结论

- **通用字帖生成**这一格已经饱和，不用再做通用版。
- 我们值得守住的只有两条差异线：**中文占格口诀**（对准老师课堂讲法）× **与课本生字表同步**。
- 直接推荐给家长：**HanZiFun**（功能最全 + 离线 + 米字格）· **喵字帖**（听写/朗读/整篇）· **ibeilly**（唯一 github.io，带朗读）。
