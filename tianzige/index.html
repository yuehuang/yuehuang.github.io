写字练习生成器

粘贴生字 → 调版式 → 导出 PDF

生字表

粘贴课本生字即可：汉字以外的字符自动忽略，重复的只留一个。

模板

「每字一行」＝范字 + 2 格描红 + 空格，一个字只练一行。
想变「范字 + 纯空格」：把描红格数拖到 0。想多练几行：改练习行数。

纸张与格型

版式

自动铺满行宽（按每行几格反推格子大小）

练习量

按笔顺拆：一格加一笔（3 画就占 3 格）
自动铺满整页（推荐）
描红只出现在第一行，从第一格起连续排；第二行起一律空着让孩子自己写。

显示内容

页眉 / 页脚

页眉下面那行（生字个数 / 格型 / 纸张 / 页码）是自动的。想加名字、日期就填这里。

导出

点右上角导出 PDF → 打印对话框里「目标 / 打印机」选 另存为 PDF，纸张 A4、边距默认即可。
描红是淡红色，彩色打印最好；黑白会变浅灰，同样能用。
预览即打印效果
